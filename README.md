# Facial Emotion Detection

A Streamlit app that detects facial emotions (angry, disgust, fear, happy, neutral, sad, surprise)
from a photo taken with your browser's camera. A CNN model classifies each detected face and a
mood meter tracks emotion counts across the session, with an option to download the session log
as an Excel file.

Click the camera widget to take a photo -- detected faces are boxed and labeled on the result.
